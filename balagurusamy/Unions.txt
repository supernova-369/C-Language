Union is a user defined data type but unlike structures, union members share same memory location.

In union, members will share same memory location. 
If we make changes in one member then it will be reflected to other member as well.

union abc {
	int a;
	char b;
}var;

int main() {
	var.a=65;
	printf("a = %d\n", var.a);
	printf("b = %c", var.b);
	return 0;
}

//var can access the member of this union.

OUTPUT:
a=65
b=A
//since they share same memory location 



Size of the union is taken according to the size of the largest member of the union.

union abc{
	int a;
	char b;
	double c;
	float d;
};

int main()
{
	printf("%ld", sizeof(union abc));
	return 0;
}


We can access members of union through pointers by using the arrow(->) operator. same as struct.

union abc{
	int a;
	char b;
};

int main(){
	union abc var;
	var.a=90;
	union abc *p =&var;
	printf("%d %c",p->a,p->b);
	return 0;
}
